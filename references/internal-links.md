Setiap anchor dipakai satu kali per halaman. Perbarui file ini setiap kali menambah atau mengubah link di badan teks. Link di navbar dan footer tidak dihitung.

## Aturan
- Dari beranda ke paket: anchor memakai variasi "paket cctv". Dari paket ke beranda: anchor memakai variasi "pasang cctv".
- Dua halaman saja belum cukup untuk target link kontekstual yang banyak. Target naik setelah ada halaman area, kontak, atau artikel: 3 sampai 5 link kontekstual per halaman panjang.
